## Блок 2: Управление системой и пользователями

### Цель работы

Изучить управление пользователями и группами в Linux, настройку прав доступа, мониторинг активности пользователей и автоматизацию с помощью Bash-скрипта.

## 1. Создание пользователей и групп

Были созданы пользователи:

- `admin`
- `user1`
- `user2`
- `user3`
- `user4`

и группы:

- `developers`
- `testers`

Распределение пользователей:

| Пользователь | Группа |
|---|---|
| `admin` | `developers` |
| `user1` | `developers` |
| `user2` | `testers` |
| `user3` | `testers` |
| `user4` | `developers` |

Основные команды:

```bash
useradd -m -s /bin/bash user1
groupadd developers
usermod -aG developers user1
```

Проверка:

```bash
id admin
id user1
id user2
```

## 2. Настройка прав доступа

Были созданы каталоги:

```text
/home/admin/data
/home/admin/logs
```

Команды:

```bash
mkdir -p /home/admin/data
mkdir -p /home/admin/logs
```

Для каталога `data` установлен доступ только для пользователя `admin`:

```bash
chown admin:admin /home/admin/data
chmod 700 /home/admin/data
```

Для каталога `logs` полный доступ предоставлен пользователю `admin` и группе `developers`:

```bash
chown admin:developers /home/admin/logs
chmod 770 /home/admin/logs
```

Проверка:

```bash
ls -ld /home/admin/data
ls -ld /home/admin/logs
```

## 3. Пароль и блокировка пользователя

Для изменения пароля `user1` использовалась команда:

```bash
passwd user1
```

Учетная запись `user2` была заблокирована:

```bash
usermod -L user2
```

Проверка:


## 4. Мониторинг пользователей

Для мониторинга активности пользователей использовались команды:

```bash
who
```

Показывает пользователей, которые сейчас вошли в систему.

```bash
w
```

Показывает вошедших пользователей и их текущую активность.

```bash
last
```

Показывает историю входов пользователей.

## 5. Автоматизация

Для автоматического создания пользователей был создан Bash-скрипт `create_users.sh`.

Список пользователей хранится в файле `users.txt`:

```text
admin:developers
user1:developers
user2:testers
user3:testers
user4:developers
```

Скрипт:

1. Проверяет права `root`.
2. Создает группы.
3. Читает пользователей из `users.txt`.
4. Создает пользователей.
5. Добавляет их в соответствующие группы.
6. Создает необходимые каталоги.
7. Настраивает права доступа.

Запуск:

```bash
chmod +x create_users.sh
./create_users.sh
```
