### 3. Настройка сети

#### 3.1. Настройка подключения через NAT

Первоначально для виртуальной машины был настроен сетевой адаптер в режиме **NAT (Network Address Translation)**.

Данный режим позволяет виртуальной машине использовать интернет-соединение основного компьютера. При этом виртуальная машина находится за виртуальным NAT-устройством VirtualBox.

В настройках VirtualBox был включён:

- **Адаптер 1 — NAT**;

Для просмотра сетевых интерфейсов и назначенных им IP-адресов в Debian использовалась команда:

```bash

```

### 5.3. Настройка входа по SSH-ключу

Для повышения безопасности и возможности подключения без постоянного ввода пароля была настроена аутентификация по криптографическому ключу.

На основном компьютере под управлением Windows была сгенерирована пара ключей с помощью команды:

```powershell
ssh-keygen -t ed25519
```

В результате создаётся пара ключей:

- `id_ed25519` — закрытый ключ;
- `id_ed25519.pub` — открытый ключ.

Закрытый ключ должен храниться только на основном компьютере и не должен передаваться другим пользователям.

Открытый ключ необходимо добавить на виртуальную машину в файл:

```text
~/.ssh/authorized_keys
```

Для этого с Windows PowerShell открытый ключ был передан на виртуальную машину:

```powershell
Get-Content $env:USERPROFILE\.ssh\id_ed25519.pub | ssh artem@10.174.5.18 "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"
```

После передачи ключа на Debian были установлены корректные права доступа:

```bash
chmod 700 ~/.ssh
```

и:

```bash
chmod 600 ~/.ssh/authorized_keys
```

Права `700` для каталога `.ssh` позволяют владельцу выполнять операции с каталогом, а права `600` для файла `authorized_keys` разрешают чтение и изменение файла только его владельцу.
